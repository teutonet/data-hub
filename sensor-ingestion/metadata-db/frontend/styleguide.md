# Styleguide

A collection of styling guidelines for a consistent style across the entire application

# Fonts

## Font-Sizes

It's generally considered best practice to limit the number of header styles to about 3–4 distinct styles to provide enough variation to create a clear content hierarchy without overwhelming the user.

### H1 (font-size: 36px) (tailwind: text-4xl)

Used for the primary page title or main heading. Should only be used once. Keep H1 at least twice normal text size for readability and impact.

### H2 (font-size: 24px) (tailwind: text-2xl)

Used for major section headings, helping to break down content under the main title.

### H3 (font-size: 20px) (tailwind: text-xl)

Supports H2 as a subheading, commonly used for subsections within a major section.

### H4 (optional) (font-size: 18px) (tailwind: text-lg)

Used sparingly for smaller, detailed sections, should only ever be used if there is no other way of structuring the information in a way that makes sense.

### Normal text (font-size: 16px) (tailwind: text-base)

Used for normal paragraphs and other text, the baseline for all other sizes.

## Boldness (font-weight: 700) (tailwind: font-bold)

Text should use boldness to get the users attention, it should be used sparingly.
We should limit the boldness to one value.
Boldness should generally only be used for titles, not for normal text.
